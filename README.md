# Oficina Gourmet Brigadeiria

Sistema web para gestão de sabores, preços por quantidade, orçamentos, vendas e agenda de eventos.

## MVP
- Dashboard comercial
- Cadastro de sabores e faixas de preço
- Orçamentos com cálculo automático
- Status de orçamento e venda
- Agenda de eventos
- Persistência local para demonstração

O projeto foi pensado para evoluir para banco PostgreSQL/Supabase e autenticação sem refazer a interface.
